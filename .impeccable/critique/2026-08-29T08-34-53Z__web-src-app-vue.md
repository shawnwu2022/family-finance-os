## Design Specificity Verdict

高度贴产品,难以被无关产品原样复用——eyebrow 英文档案标签与中文标题的对照、语义色与数据质量的强绑定、AI 结果「提问时查看」锚定行,都是产品哲学在像素层的直接投影。最薄弱处是 Portfolio 表单:10 字段平铺、「资产引用 ID」暴露内部概念。

确定性扫描:detector 在 --json 与 --no-config 下均 0 发现。浏览器证据:44px 步进按钮命中自身、与刷新按钮零重叠(桌面间距 10.4px)、快捷键提示桌面显示/移动隐藏、撞名提示精确匹配琥珀 #a16207——前两轮全部修复经实测确认落地。B 另发现:步进器 <select> 实测仅 104×19px——共享 padding 规则漏了 select。

## What's Working

1. 数据诚实作为情感设计:seq 守卫 + dataPeriod 双轨 +「可能已不是最新」+ 中性历史月药丸。
2. AI/确定性分界的三重物化:雾白底容器 + meta 声明行 + review-box 引用线。
3. 极简机件达成安全交互:角色 :value+confirm+失败拨回、asset_ref 琥珀提示+保存前确认。

## Priority Issues

1. [P1] Advisor 失败被误标为安全策略拦截 — submitAdvisor 把所有异常塞进 blocked:true,网络抖动渲染成「已被安全策略阻止:rate_limited」。修复:服务端真 blocked 才用 --blocked 样式;网络/5xx 显示中性「顾问暂时不可用」,保留上次成功回答。
2. [P1] errorText() 本地化碎片化 — Portfolio/Members/Advisor 三处仍直出原始码。修复:提升为 web/src/errors.ts 共享模块,四处统一。
3. [P1] 成员停用是不可逆死路且未告知 — 已核实后端只有 List/Create/UpdateRole/Disable,无 re-enable。修复:补 enable API+按钮;或短期至少在确认文案写明不可逆。
4. [P2] Portfolio 表单无分组 + 取消静默丢弃 — 10 字段平铺;误触「取消」即丢全部输入。修复:按身份/估值/来源分三组;dirty 时取消需 confirm;Esc 走同一确认。
5. [P2] 断点契约漂移 + 步进器 select 失控 — PortfolioPanel 用 680px(契约禁止第三个值);stepper select 仅 19px 高(padding 规则漏 select)。修复:680→719.98;select 加入共享 padding 规则。
